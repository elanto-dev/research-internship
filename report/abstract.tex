\begin{abstract}
This study investigates the role of \acrfull{gpt} in developer-chatbot interactions within software development contexts. Using a combined dataset of over 10 000 conversations sourced from GitHub (commits, issues, discussions, pull requests, code files, repositories) and HackerNews, we apply text mining techniques like n-gram extraction, \acrfull{spm}, and topic modeling to analyze the functional expectations developers place on \acrshort{gpt}. The results reveal a strong contextual alignment between the source of the conversation and the role \acrshort{gpt} is assigned, ranging from scripting automation and debugging assistance to design planning and narrative generation. These findings demonstrate that developers use \acrshort{gpt} not merely as a code generator, but as a multifaceted collaborator.
\end{abstract}
